Selected projects

Polymer property prediction

From repeat-unit SMILES to five polymer properties: a chemistry-aware pipeline combining molecular graphs with physics-informed residual learning.

  • Benchmarks GraphGPS, PNA, GATv2, and GINE with cluster-based cross-validation.
  • Repository-reported five-fold OOF weighted MAE: 0.05154 for the physics-cascade hybrid.

Crystal Symmetry Lab

A browser-based 3D workbench for exploring crystal symmetry, strain-induced symmetry breaking, and physical-property tensors.

  • Visualizes space-group operations and atomic site symmetries from CIF and VASP structure files.
  • Connects strain and order parameters to subgroup changes and symmetry-allowed tensors.

WARDEN · AI co-scientist

An in-silico workflow for atomic layer deposition research, combining agent-guided screening with deterministic physics checks.

  • Includes bounded feedback loops, evidence acquisition, persistent records, and reaction-kinetics workflows.
  • Research prototype: the offline demo is synthetic; live services and MACE scientific performance remain unverified in the repository.

Piezoelectric Modulus Prediction Using Machine Learning

Developed a complete machine learning pipeline to classify and predict the piezoelectric modulus for a large set of inorganic materials from the JARVIS database.

  • Trained on 1,354 inorganic materials from JARVIS; reached 78% classification accuracy.
  • Used crystal symmetry features and transfer learning to achieve a regression RMSE of 0.49.
